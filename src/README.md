# Клієнтська частина «Світ Іграшок»

Магазин працює через Node.js API. Для запуску перейдіть на рівень вище та виконайте `npm ci`, `npm run admin`, `npm start`.

Повна інструкція, структура коду та пояснення для навчання — у [README.md](../README.md).
Відкриття `index.html` через `file://` або Live Server не підключає базу даних.
